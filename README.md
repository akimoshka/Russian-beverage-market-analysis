# Анализ российского рынка напитков 2024–2030

Тестовое задание для **Альфа-Банка** по анализу российского рынка безалкогольных и слабоалкогольных напитков.

В рамках проекта собраны и структурированы открытые рыночные данные за 2024–2025 гг., построены сценарии развития рынка до 2030 года и разработан интерактивный аналитический dashboard.

## Интерактивный dashboard

**[Открыть dashboard](https://akimoshka.github.io/Russian-beverage-market-analysis/)**

Dashboard содержит ключевые показатели рынка, динамику натурального и стоимостного объёма, структуру рынка и сравнение прогнозных темпов роста отдельных сегментов.

## Цель проекта

Провести анализ российского рынка напитков и оценить возможную динамику его развития в 2026–2030 гг.

В анализ включены следующие категории:

- газированные напитки;
- негазированные напитки;
- энергетические напитки;
- пиво;
- пивные напитки.

Рынок рассматривается как в **натуральном выражении (млн литров)**, так и в **стоимостном выражении (млрд рублей)**.

## Методология

Работа состоит из нескольких этапов:

1. Сбор данных из открытых источников за 2024–2025 гг.
2. Приведение показателей к сопоставимым единицам измерения.
3. Разделение данных на наблюдаемые значения и аналитические оценки.
4. Формирование базового уровня рынка по каждой категории.
5. Построение трёх сценариев развития:
   - Conservative;
   - Base;
   - Optimistic.
6. Прогноз натурального объёма рынка до 2030 года.
7. Расчёт CAGR (Compound Annual Growth Rate — среднегодового темпа роста).
8. Оценка рынка в стоимостном выражении на основе натурального объёма и средней цены.
9. Визуализация результатов в интерактивном dashboard.

Из-за ограниченной длины исторического ряда прогноз построен **сценарным методом**, а не с использованием временных рядов вроде ARIMA или Prophet.

Показатели, для которых отсутствуют полностью сопоставимые публичные данные, явно обозначаются в модели как аналитические предположения (`model_assumption`).

## Основные результаты

В базовом сценарии модель показывает:

- совокупный стоимостный объём анализируемых сегментов в 2025 году — около **2,14 трлн ₽**;
- прогнозируемый объём к 2030 году — около **2,80 трлн ₽**;
- совокупный натуральный рынок остаётся относительно стабильным;
- наиболее быстрорастущим сегментом в натуральном выражении являются **энергетические напитки**;
- рост рынка в денежном выражении обусловлен как изменением натурального спроса, так и ценовой динамикой.

Все значения 2026–2030 гг. являются результатом сценарного моделирования и не представляют собой официальные прогнозы рынка.

## Dashboard

Dashboard автоматически строится на основе подготовленного датасета и включает:

- KPI рынка;
- динамику рынка в натуральном выражении;
- динамику рынка в стоимостном выражении;
- структуру рынка по категориям;
- CAGR по сегментам;
- сравнение показателей 2025 и 2030 гг.;
- итоговую таблицу ключевых показателей.

Для генерации dashboard:

```bash
python src/dashboard.py
```

После запуска создаётся HTML-версия dashboard для публикации через GitHub Pages.

## Источники и ограничения

В работе используются открытые данные отраслевых и статистических источников. Для каждого исходного показателя в аналитическом notebook фиксируются источник, период, единица измерения и статус данных.

При интерпретации результатов необходимо учитывать различия в методологиях источников, границах товарных категорий и доступности статистики. Поэтому часть показателей используется как аналитическая оценка, а прогноз 2026–2030 гг. представлен в виде сценарной модели.
